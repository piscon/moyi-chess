墨弈 Moyi — a chess engine in 4 KB of Python. A 0x88 board, copy-make,
an incremental tapered evaluation (material + piece-square tables), and
one negamax search with alpha-beta, PVS, a transposition table,
quiescence and check extensions, thinking under a fixed node budget —
never a clock — so every trial replays move for move. Written in the
spirit of ink on paper: few strokes, no waste.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
